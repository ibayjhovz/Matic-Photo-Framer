# Simple Automatic Photo Framer

A fully client-side tool to layer images with frames and download them instantly inside a compiled `.zip` file. Built entirely using standard HTML5 canvas rendering and JavaScript.

## Live Application
You can interact with the live tool directly right inside your browser framework through GitHub Pages.

## No Server Storage Overhead
Because this application is built out using localized browser scripts, processing happens directly on your device CPU memory space. No images are ever uploaded or transmitted over external network servers, maximizing user security data privacy.
